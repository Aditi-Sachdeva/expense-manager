# Expense Manager

A simple personal finance web app to track income, expenses, budgets and savings goals. Built with plain HTML, CSS and JavaScript (no frameworks).


## Features

- **Dashboard**: overview of total balance, income, expenses and net savings
- **Transactions**: add and view income and expenses
- **Accounts**: manage bank and cash accounts
- **Categories**: organise transactions by category
- **Budgets**: set monthly budgets
- **Goals**: track financial goals
- **Groups**: shared expenses
- **Alerts**: smart alerts when spending goes off track

## Tech Stack

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6)
